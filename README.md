# Halloween-in-Python 🎃

Draw Halloween in Python Turtle — a glowing jack-o'-lantern conjured line
by line on a black canvas.

## What it does

`halloween.py` uses Python's built-in `turtle` graphics to draw a pumpkin:
an orange circle body (`#DC5F00`), gold triangle eyes and nose, and a
toothy grin — all on a 900×650 black screen, no extra libraries needed.

## Run it

```sh
python3 halloween.py
```

Needs a desktop with Python 3 and Tk support (turtle is in the standard
library). It opens a window and draws — that's the whole trick, and the treat.
